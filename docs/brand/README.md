# hatswap brand

The mark is two top hats, one upside down, turned around the same centre: one hat comes off as the other goes on.

| File | Use |
|---|---|
| `hatswap-lockup-light.svg` / `hatswap-lockup-dark.svg` | Mark and wordmark, for light and dark backgrounds |
| `hatswap-mark-light.svg` / `hatswap-mark-dark.svg` | The mark alone |
| `hatswap-mark-mono.svg` / `hatswap-mark-white.svg` | One colour, for places that cannot use orange |
| `app-icon.svg`, `app-icon-512.png`, `apple-touch-icon.png` | The mark on a rounded dark tile |
| `favicon.svg` (follows light/dark), `favicon-32.png` | Browser icons |
| `social-card.png` | 1280×640 link preview (GitHub: Settings → Social preview) |

**Colours**

| | Hex | Used for |
|---|---|---|
| Clay | `#D97757` | The upright hat; the accent everywhere else |
| Slate | `#141413` | The second hat and text on light backgrounds; dark backgrounds |
| Ivory | `#FAF9F5` | The second hat and text on dark backgrounds |

**Rules**

- Keep the orange hat on top. Turned the other way, it reads as a different mark.
- Leave clear space of at least one brim height (20 of the mark's 256 units) on every side.
- Smallest size: 16 px for the mark, 96 px wide for the lockup.
- Don't recolour the hats, add outlines or shadows, or set the wordmark in another font.

The wordmark is JetBrains Mono Bold (SIL Open Font License), converted to outlines, so no font is needed to display it.
